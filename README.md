# Tourisme Yakro

Site vitrine statique présentant quelques lieux touristiques de Yamoussoukro.

## Structure

- `index.html` : page principale du site
- `css/styles.css` : styles, responsive et animations
- `js/script.js` : navigation mobile, modale, slider et formulaires
- `images/` : images utilisées par les cartes, la galerie et les modales
- `logo.svg` : logo local du site

## Lancer le projet

Ouvrir `index.html` directement dans un navigateur.

## Notes

Les formulaires sont simulés côté navigateur. Pour une version de production, il faudra ajouter un backend ou un service externe pour recevoir les messages et les inscriptions à la newsletter.
